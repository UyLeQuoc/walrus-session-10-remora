# H1–H6 exit: Huấn's web goals, web side (Oct 29, 2026)

Goals: [H1](../goals/huan-01-u13-review.md) to [H6](../goals/huan-06-account-exit.md), index in
[goals README](../goals/README.md). Decisions: [ADR-0071](../adr/0071-huan-goals-without-e2e.md) (no E2E while the
burner is empty) and [ADR-0072](../adr/0072-accept-ascii-ocean-and-lucide-icons.md) (accept ADR-0041 as built;
icons only from `lucide-react`). Requests for Uy: [2026-10-29-huan-to-uy-h2-h6-contract.md](../handoffs/2026-10-29-huan-to-uy-h2-h6-contract.md).

**Scope:** everything here is in `apps/web` (plus docs). No server, schema or Move code changed. The routes for
`/status`, `/reef` and `/p/:token`, and every backend endpoint, wait on Uy's contract PR. Until then the pages
show a quiet "not available yet" state and run on local fixtures.
