4. The pool check now runs before the questions, so A's session is surely still live when C arrives.

6. **Oct 23: both Tatum keys answered `402`** to every call (out of credits), so nothing on the server could read the chain.
   - `diagnose` said the deployment ids "don't exist on testnet", which was the wrong fix.
   - It now says `couldn't check …` and gives the Tatum fix (402 out of credits, 401/403 a refused key, 429 the rate limit), and health's `tatum` item does the same (`tatumTrouble` in `apps/server/src/ops/diagnose.ts`).

**Cost per session:** about 0.002 SUI of the playground wallet's gas (the issue plus the revoke), and 0.01 USDC per paid answer. Over both runs, the burner went from 0.2274 to 0.2196 SUI, and from 0.98 to 0.96 USDC.

   - Recalls answered `500 Internal server error`.
   - Writes were accepted, then failed in the relayer's background job: a probe write got `Embedding API error (401 Unauthorized): User not found`. That's the relayer's own embedding provider; Remora sends no embedding key.
   - The read API listed nothing newer than Oct 21 18:30 UTC.
   - `/lab/health`, `diagnose` and the memory doctor all said ok. They now report it:
     - health's new **`memory writes`** item reads the failures our own calls saw;
