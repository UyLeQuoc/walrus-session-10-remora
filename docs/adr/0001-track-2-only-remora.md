# ADR-0001: Compete in Track 2 only, with Remora

- **Status:** Accepted
- **Date:** 2026-10-18
- **Deciders:** Uy Le

## Context
The hackathon has three tracks, and its rules allow **one submission per person**. We explored ideas for
every track (`docs/archive/`). The owner is strongest in Sui infrastructure and has already published an
audit of Sui's agentic-finance stack ("Rails Before Robots", Oct 15, 2026).

## Decision
Enter **Track 2, Smart Agents for Real Life**, with one product, **Remora**: always-on agents with owned
memory (Walrus Memory), contract-level budgets (Sui) and receipts. The other ideas are parked in
`docs/archive/`.

## Consequences
- The Best Walrus Memory prize ($500) is also in reach.
- The blog post can be a sequel to the published audit.
- Ideas for the other tracks are reference only.
