# packages/move/remora

The Remora Move package: the `disc` module (app type `DISC` for app-bound allowances, ADR-0003), the `hatchery` module (template provenance, ADR-0012) and their `sui move test` suites.

- **Owner:** Uy Le (`@UyLeQuoc`) (see `docs/team-split.md` §2)
- **Features:** E1, I6, M6, G4
- **Status:** scaffold. Nothing is implemented yet.

Every Move change gets a PR. Only Uy publishes to mainnet; the IDs go in `packages/schema/src/deployments.ts`.
