# ADR-0011: Scope: an MVP ship set of 68 features, plus a backlog

- **Status:** Accepted
- **Date:** 2026-10-18
- **Deciders:** Uy Le

## Context
The full catalog has 132 features, which is too much for 22 days with certainty. The owner wants an MVP
that still has enough features to feel complete.

## Decision
- Commit to the **ship set** (68 features, listed in `remora-features.md` §0). It covers the demo path,
  every hackathon requirement, Hatchery core and key UX.
- The other 64 features are the backlog, built in wave order after the ship-set items pass E2E.

## Consequences
- The wave plans stay, but within each wave the ship set comes first.
- Anything unfinished becomes roadmap design in the README.
