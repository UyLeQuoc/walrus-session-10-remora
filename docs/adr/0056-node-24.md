# ADR-0056: Node 24 everywhere, matching CI, and a deploy image that builds

- **Status:** Accepted
- **Date:** 2026-10-24
- **Deciders:** Uy

## Context
CI has run the application checks on Node 24 (`actions/setup-node`, `node-version: 24`) since the bootstrap. The rest of the repo still said Node 20:
- `.nvmrc` and the root `engines` (`>=20`);
- the deploy image (`FROM node:20-slim`);
- `docs/code-rules.md`.

So the API and runtime deployed on a Node version that CI never tested. Node 20 also leaves maintenance in 2026.

While checking the image on Node 24 (Oct 24), we found it didn't build at all:
- The `Dockerfile` came from hippo and copied five hand-listed workspace manifests.
- Remora has 20, so `bun install --frozen-lockfile` refused the lockfile.
- A Railway deploy would have failed at install.
- `.dockerignore` also sent `reference/` (the hippo clone) into the build context.

## Decision
- **Node 24** is the runtime everywhere:
  - `.nvmrc` is `24`;
  - the root `engines.node` is `>=24`;
  - the deploy image is `node:24-slim`, still with Bun copied in from `oven/bun` for package management;
  - CI stays on 24.
- `docs/code-rules.md` says Node 24.
- **The image copies every workspace's `package.json`.** It doesn't keep a list: a `manifests` stage finds them all. The install layer stays cached when only sources change, and a new workspace can't break the install again.
- **`.dockerignore`** leaves out `reference/` and everything in `e2e/` but its `package.json`.
- **Verified locally (no deploy):**
  - the image builds;
  - `node --version` is v24.22.1;
  - `@remora/schema`, `@remora/chain`, `@remora/disc-sdk` and the server's ops modules load;
  - neither `.env` nor `reference/` is in the image.

## Consequences
- Local, CI and the deploy image run one major version.
- The `jsdom` pin to 26 was there because 30 needs Node 22. Node 24 removes that reason, so the pin can be lifted in its own change, with the web tests run.
- Railway builds from the `Dockerfile`, so the next deploy picks Node 24. Vercel's web build sets its Node version in the project settings: set it to 24 there too.
