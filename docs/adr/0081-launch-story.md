# ADR-0081: The launch tells one story, with built beats only

- **Status:** Accepted
- **Date:** 2026-10-31
- **Deciders:** Uy (written by Uy's agent; Uy asked to "fix everything left")

## Context
- **What Walrus judges rewarded last session.** In Walrus Session 8, the same team's hippo took 2nd place
  behind Playbook. The organizers wrote: "it is not always about building the most technical thing. A
  simple product with a great use case is just as valuable." Playbook won with:
  - one relatable story;
  - memory that changes the first screen;
  - a memory on/off comparison;
  - an honest "what went wrong".
- **Remora's risk is the same.** It has 134 features and 80 ADRs, and its README opened on a nine-row
  feature table.
- **The old demo script promised beats that aren't built:** a SuiNS name, the Telegram Mini App, Walrus
  Sites hosting, and a Day 14 that the window can't reach.
- **The money rails came before the window** ([ADR-0075](0075-pre-window-work-stated.md)), so the story
  should lean on what the window added.

## Decision
- **One story, everywhere: Uy's wallet, watched.**
  - An airdrop goes Sentinel → Scout and gets a paid check.
  - An injection is blocked, and the Disc aborts it onchain.
  - A 👎 becomes a rule, and the next one is silent.
  - A key that pays without a decision is caught.
  - The same memory works in Claude Code.
- **Where the story goes:**
  - the README opens with "In one minute" (four beats);
  - the demo script in [remora-plan.md](../remora-plan.md) uses only built beats, and says what to
    prepare before recording;
  - the blog draft gains "What's real, what isn't" and "What went wrong".
- **Unbuilt items move to the roadmap, not the pitch:** SuiNS, the Mini App, Walrus Sites, Day 14.
- **Outward-facing drafts are written, never sent.** Uy reviews them and sends them:
  - the X and LinkedIn posts;
  - the MemWal issues ([docs/launch](../launch/)).

## Consequences
- The video is recordable after U9's deploy and a few days of dogfooding. It doesn't depend on the
  mainnet pass.
- Every claim in the README's first screen has a proof row with its date and how it was tested.
- **The mainnet pass (U10) stays Uy's call.** The submission needs Walrus Memory on mainnet, which it
  already is, and Tatum RPC, which testnet satisfies. Mainnet money isn't required, so U10 is
  recommended only if time is left after U9, the video and the blog.
